# Sangam releases

Public download mirror for **Sangam** — a simple, private, end-to-end-encrypted
messenger for friends. *Where friends meet.*

This repo contains no source code — only released APK files so the app's
built-in updater can check for and download new versions without a login.
The app itself lives in a private repository.

## Install

Download `Sangam-vX.Y.Z.apk` from the [latest release](https://github.com/sekelan-ideas/Sangam-releases/releases/latest),
open it on your Android phone, and allow "Install from this source" when
Android asks. That's it.

> Sangam stores only ciphertext on its server, uses the Signal protocol for
> end-to-end encryption, shows no ads, and never asks for your phone number.
